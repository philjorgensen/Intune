# Think BIOS Config Tool V2 - Supervisor Password Change

Changes the BIOS supervisor password on Lenovo devices with an Intune Win32 app, using an encrypted password change file generated by the **Think BIOS Config Tool V2** and applied by the **Lenovo.BIOS.Config** PowerShell module. The supervisor password is never exposed in plain text.

Full walkthrough: [Changing the BIOS Supervisor Password with Intune and the Think BIOS Config Tool V2](https://blog.lenovocdrt.com/changing-the-bios-supervisor-password-with-intune-and-the-think-bios-config-tool-v2/)

> Password change files created with the original HTA-based Think BIOS Config Tool are not compatible with V2. Recreate the file with the V2 tool. The V1 solution lives in [`../ThinkBiosConfigTool`](../ThinkBiosConfigTool).

## Requirements

- An existing supervisor password on target devices. TBCT V2 does not set an initial password; use [System Deployment Boot Mode](https://docs.lenovocdrt.com/ref/bios/sdbm/) or Absolute Remote SVP for that.
- Think BIOS Config Tool V2 (`ThinkBIOSConfigUI.ps1`) and the `Lenovo.BIOS.Config` module on an admin workstation to generate the password change file
- [Microsoft Win32 Content Prep Tool](https://github.com/microsoft/Microsoft-Win32-Content-Prep-Tool) to build the `.intunewin`

## Files

**Update-SupervisorPassword.ps1** - Install script
- Imports the `Lenovo.BIOS.Config` module packaged next to the script
- Applies the first `.ini` password change file found in the package with `Import-LnvPasswordChangeFile`
- Logs to `C:\ProgramData\Lenovo\ThinkBiosConfig\Logs\PasswordChange.log`
- Exits `3010` on success (soft reboot) and `1` on failure
- Set `$SecretKey` to the passphrase used when generating the password change file

**Test-OOBEComplete.ps1** - Requirement rule #1
- Returns `$true` once OOBE is complete, so the app installs only during OOBE (ideal for pre-provisioning)

**Test-SupervisorPassword.ps1** - Requirement rule #2 (optional)
- Returns `$true` when `Lenovo_BiosPasswordSettings.PasswordState` is non-zero (a password is set)

**Detect-SupervisorPasswordChange.ps1** - Detection script
- Reads the latest TBCT V2 log (`TBC_Log.log`) and confirms every step of the last `Import-LnvPasswordChangeFile` run reported `Success`

## Packaging

Stage the module, install script, and password change file in one source directory:

```powershell
Save-Module -Name Lenovo.BIOS.Config -Path "C:\Source\IntuneWin32\TBCT"
# copy Update-SupervisorPassword.ps1 into C:\Source\IntuneWin32\TBCT

Import-Module Lenovo.BIOS.Config -Force
Export-LnvPasswordChangeFile -FileLocation "C:\Source\IntuneWin32\TBCT\svp.ini" -Type svp
```

`Export-LnvPasswordChangeFile` prompts for the encrypting passphrase, the current supervisor password, and the new supervisor password. The file can also be created from the GUI under **Actions > Change Password > Create Password Change File**.

```
C:\Source\IntuneWin32\TBCT\
    Lenovo.BIOS.Config\
        <ModuleVersion>\
            ├─ Lenovo.BIOS.Config.psd1
            ├─ Lenovo.BIOS.Config.psm1
            └─ ...
    Update-SupervisorPassword.ps1
    svp.ini
```

Build the package:

```
IntuneWinAppUtil.exe -c "C:\Source\IntuneWin32\TBCT" -s Update-SupervisorPassword.ps1 -o "C:\Source\IntuneWin32\" -q
```

## Intune configuration

| Setting | Value |
|---|---|
| **Install command** | `%windir%\sysnative\WindowsPowerShell\v1.0\powershell.exe -ExecutionPolicy Bypass -File ".\Update-SupervisorPassword.ps1"` |
| **Uninstall command** | `cmd.exe /c` |
| **Install behavior** | System |
| **Device restart behavior** | Determine behavior based on return codes (so `3010` is honored) |
| **Minimum OS** | Windows 11 21H2 |
| **Requirement rule #1** | Script `Test-OOBEComplete.ps1`, 64-bit, Boolean, Equals **No** |
| **Requirement rule #2** (optional) | Script `Test-SupervisorPassword.ps1`, 64-bit, Boolean, Equals **Yes** |
| **Detection rule** | Custom script `Detect-SupervisorPasswordChange.ps1` |

## Deployment

Assign to a device group. In an Autopilot pre-provisioned deployment, add it as a blocking app during ESP.

## Notes

- A supervisor password change takes effect after a reboot.
- If the wrong passphrase is supplied and installs fail repeatedly, the BIOS may show a "Security password retry count exceeded" prompt on the next reboot.
- Validate on a single lab device before broad deployment.
